# Imperial Algothon

Python source code and the example notebook for the Imperial Algothon trading-bot project.

- `final_bot.py` — final bot implementation
- `bot_template.py` — starter template
- `test_predictions.py` — prediction tests
- `old/` — earlier bot and algorithm versions
- `example.ipynb` — example notebook

Generated bytecode and PDF write-ups are excluded.
